## 🚀 Current Projects

### 🎮 Nexora Engine

**Nexora** is a Python-based 2D game engine with a focus on custom rendering, audio, physics, UI systems and editor tools.

The long-term goal is to use it for a dark steampunk/cyberpunk game with pixel-art graphics, exploration, RPG systems and base building.

🔗 [View Nexora Engine on GitHub](https://github.com/Lainupcomputer/Nexora)

### 🐝 STWG Web

**STWG Web** is a clan and community management platform connected to a Discord bot.

Features include:

- Member and profile management
- Discord roles, permissions and licenses
- Training, meetings and tickets
- Warehouse and market systems
- Messages, announcements and rules
- Market monitoring and price alerts
- STWG Radio integration
- MariaDB database with Webpanel-to-Discord communication

🔗 [View STWG Web on GitHub](https://github.com/Lainupcomputer/stwg-web)

### 🎛️ BeatForge

**BeatForge** is a self-developed hardware and software project for the Raspberry Pi.

It is designed as a modular and expandable digital groovebox inspired by the legendary Korg ESX-1. BeatForge combines custom hardware with a dedicated software platform for beat production, sampling and electronic music workflows.
